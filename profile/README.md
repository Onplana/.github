# Onplana

**AI-native project and portfolio management for teams that need a real schedule.**

Gantt with critical path and baselines on every plan, portfolios with health rollup, proposal governance with gate reviews, resource capacity, timesheets and earned value, with AI that drafts the plan and flags what is about to slip. Claude, ChatGPT, Copilot and Cursor can work in your projects over MCP.

## What you'll find here
This GitHub organization hosts our open-source work: the integration surface around Onplana, not the product itself.

- **Model Context Protocol (MCP) server:** connect Onplana to Claude, ChatGPT, Cursor, Gemini, GitHub Copilot, and any MCP-compatible AI agent
- **SDKs and clients:** official TypeScript and Python clients for the Onplana API
- **Example integrations:** reference code showing Onplana with Claude Desktop, Slack, GitHub Actions, and more
- **Developer tooling:** CLIs, scaffolding, and helpers for teams building on Onplana

The Onplana application itself is closed-source SaaS at [app.onplana.com](https://app.onplana.com).

## Why Onplana

Most project management tools optimize for software teams or generic task management. Onplana is built for **PMOs and portfolio managers** who need real depth:

- **A real scheduler:** critical path and float, all four dependency types with lag, multiple baselines, on every plan including Free
- **Bring your files:** native `.mpp`, Project XML, Primavera P6 and Planner imports with dependencies, constraints, custom fields and costs intact; [Onplana Schedule](https://onplana.com/schedule), a free desktop app for Windows and Mac, opens them without a Microsoft Project licence
- **Governance pipelines:** 12-stage gate reviews, classification routing, change control boards, multi-reviewer approvals
- **Earned Value Management:** PV / EV / AC / CV / SV / CPI / SPI computed natively, not bolted on
- **Scenario planning:** portfolio-level what-if analysis with budget, capacity, and timeline levers
- **AI-native workflows:** plan generation, risk detection, status report generation, intake parsing, executive summaries
- **AI agents as members:** agents connected over MCP hold assignments and answer in comment threads, and every write they make is audited and reversible
- **Configurable permission matrix:** 5 org roles × 5 project roles × 4 posture presets, with custom role support
- **Generous free tier:** no credit card, no time limit, includes the Gantt and the AI assistant
